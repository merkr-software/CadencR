## What this page is for

The unified agent list is the **see-everything-at-once** view for your agent sessions.

If you only have one session open, life is simple. If you have eight, fifteen, or one suspiciously large pile of them, this view helps you stay oriented without opening each session one by one.

Use it when you want to:

- find a session quickly
- compare several sessions at a glance
- keep important work easy to reach
- scan a busy workspace before deciding what to open next

## How to find the right agent fast

Start with the filter text box. Type any word you remember from the session name, task, or feature. You do **not** need to remember the exact title. This is a docs page, not an escape room.

Then use the available filters to narrow things down further when the list gets crowded.

| If you want to...                   | Try this                                              |
| ----------------------------------- | ----------------------------------------------------- |
| Browse visually                     | Stay on the default grid                              |
| Pack more sessions on screen        | Use the **per-row stepper** to raise the grid density |
| Keep today's important work nearby  | **Pin** those sessions (<kbd>⌘<ShiftIcon />P</kbd>)   |
| Move faster with less mouse mileage | Use **keyboard navigation** (<kbd>⌘⌥</kbd> + arrows)  |

A few practical tips:

- Start broad, then add another word if needed.
- Raise the per-row count when you want dense, fast scanning; lower it when you want larger preview tiles.
- If you find a session you will revisit, pin it right away.
- Use <kbd>⌘<ShiftIcon />F</kbd> to jump straight into the search box without reaching for the mouse.

## How pinning and scanning help

Pinning is for the sessions you care about **right now**: active features, review work, or anything you keep bouncing back to. Pinned conversations also appear in a global **Pinned** section above the project list in the sidebar, so important work stays reachable even when it belongs to a different project.

Scanning is different from reading every session in full. In this view, your job is to recognize the right item quickly, not study everything like it will be on a quiz. Skim the list, spot the session you need, then open it when you are ready to work.

<DocCallout title="Small but useful tip" variant="tip">
  If your pinned section starts looking like a second full list, it is time for a quick cleanup.
  “Pinned” should mean **important now**.
</DocCallout>

## Good habits when you have many sessions

You do not need a complicated system. A few boring habits work surprisingly well:

- Keep session names clear and human-readable when possible.
- Use **pins sparingly** so the sidebar Pinned section and unified list both stay useful.
- Bump the per-row count up for quick morning or end-of-day check-ins, then drop it back down when you settle into a session.
- Unpin sessions when they stop being active.
- Scan the unified list first when you feel lost instead of opening random tabs one by one.

If you are managing lots of sessions, the goal is not perfect organization. The goal is being able to answer one simple question fast: **which session needs me next?**
