If Cadencr is where you keep work moving, shortcuts help you spend less time reaching for the mouse.

You do **not** need to memorize every key combo on day one. Learn the few that save you the most time, then add more as you go.

## How shortcut scopes work

Cadencr binds shortcuts to **scopes** instead of throwing every binding at the global keyboard listener. The same combo can do different jobs in different scopes — that is normal and on purpose.

The scopes you will meet most often:

- **Global** — work anywhere in the app.
- **Feature panes** — the Agent / Editor / Terminal / Git tabs inside a feature workspace.
- **Feature actions** — header buttons (commit, push, branch picker, …).
- **Agent & prompt** — when the Agent tab is focused.
- **Plan approval / Tool permission / Agent questions** — temporary scopes that turn on while a prompt is showing.
- **Diff viewer** — when the Git tab is focused.
- **Editor / Terminal / Browser** — when those tabs have focus.

## Three habits worth forming

1. **Anchor on three keys**: <Kbd>⌘</Kbd> <Kbd>K</Kbd> for the command palette, <Kbd>⌘</Kbd> <Kbd>/</Kbd> for help, and <Kbd>⌘</Kbd> <Kbd><ShiftIcon /></Kbd> <Kbd>A</Kbd>/<Kbd>E</Kbd>/<Kbd>T</Kbd>/<Kbd>G</Kbd> for the four panes.
2. **Move with the keyboard**, not just type with it. <Kbd>⌘</Kbd> <Kbd>⌥</Kbd> + arrows works almost everywhere there is something to move between. In the Browser, <Kbd>⌘</Kbd> <Kbd>L</Kbd> jumps straight to the address bar.
3. **Use approval keys** when the agent pauses. <Kbd>⌘</Kbd> <Kbd>Y</Kbd> / <Kbd>⌘</Kbd> <Kbd>N</Kbd> / <Kbd>Esc</Kbd> is a much smoother review loop than reaching for the mouse on every prompt.
