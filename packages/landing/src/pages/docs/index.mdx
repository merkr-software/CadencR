## What you can learn here

These docs are here to help you:

- understand what CadencR is without learning a pile of jargon first,
- find your way around the main screens,
- get more comfortable with agent sessions, Git, the editor, terminal, and Browser,
- move faster with practical tips like [Shortcuts](./shortcuts/), [Custom Actions](./custom-actions/), and [Browser](./browser/).

## How to use these docs

You do not need to read everything in order. Use it like a reference, not a course.

- **Start Here** explains the big picture and the main places you will spend time.
- **Core Views** helps you stay oriented while work is happening.
- **Features** covers the tools you will reach for once you are in motion.
- **Reference** is the look-it-up section for approvals, worktrees, and settings.
