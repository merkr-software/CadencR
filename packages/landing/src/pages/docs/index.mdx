Use these guides to set up your agents, choose a task's working context, and review its result. The marketplace guides cover **CadencR v0.16.0**; each guide shows its reviewed version. Ready to install the desktop app? Follow the [macOS and Linux installation guide](./installation/).

Building an extension? The [libraries overview](./libraries/) links to dedicated **npm packages** and **Rust crates** guides for custom tabs and agent providers. Library versions are independent of the desktop version shown above.

Find extensions in the [Marketplace](./marketplace/), or follow [Publish to the marketplace](./marketplace-publishing/) to release your own.

## Before your first prompt

1. Install and authenticate an agent CLI on the host.
2. Register your project folder.
3. Check the provider/model and branch/worktree controls.
4. Describe one task, then inspect files, checks, and Git before publishing changes.

New conversations use the provider and model from your last accepted manual prompt across projects, unless the conversation has an override. Add providers through the [Marketplace](./marketplace/) or a local ACP connector.
