Session view is the transcript and composer for one conversation. Use it to follow progress, inspect outputs, and decide what the agent should do next.

## Read at the level you need

Normal conversation mode shows the running transcript. Optional **Summary** mode folds completed turns into a tool recap and final answer. Expand a turn to read its intermediate actions, then collapse it again from the footer.

Tool cards expose commands, results, file changes, and reasoning when the provider reports them. Sub-agent activity appears in compact timelines; expand a timeline for its detailed history. Large outputs can show a preview with an explicit action to load the full content.

## Find an earlier prompt

- Use `Cmd/Ctrl+F` for in-conversation text search. `Enter` and `Shift+Enter` move between matches.
- Use the **message navigator** on the right edge to preview a user prompt on hover and jump to it.
- `Alt+Up` and `Alt+Down` move between user prompts, including older prompts that are not in the current history window.
- Disable the navigator in **Settings → Appearance** if you prefer.

Scrolling upward preserves your reading position while the agent continues. The auto-scroll control returns you to following the latest output.

## Inspect rich content

Code blocks, inline changes, diagrams, and images are rendered in the transcript. Mermaid blocks offer source/diagram controls and a zoomable viewer. Rendered HTML is sanitized. File-and-line references can open the relevant location in Editor or Neovim; Auto layout can keep it beside the agent.

Supported local document links can open in their default application. Missing or unsupported targets report an error instead of launching silently.

## Copy a useful result

Use **Copy as** for a selection or message block to choose plain text, Markdown, Slack formatting, or email formatting. On touch devices, long press supports text selection and the mobile copy menu.

## Understand context usage

The context indicator shows provider-reported token information. Open its details for input, output, total tokens, and compaction information. If the provider has not reported its context-window size, CadencR shows known counts with a pending state instead of guessing a percentage.

Context usage describes the current conversation. [Usage Stats](../usage-stats/) records durable activity across conversations.

## Continue, stop, or branch

Send a follow-up to refine the current task. A prompt sent while the agent is working can steer that turn; its receipt indicates delivery. Answer plan, permission, or question requests using the available controls.

`Esc` stops the current agent in its conversation scope. The global stop command can stop all running agents; see [Shortcuts](../shortcuts/) for its binding.

Use [Rewind & Fork](../rewind-and-fork/) on an eligible persisted user message to return to an earlier point or create a conversation branch. **Sync from CLI** in Session Info appends missing events from supported provider conversations continued outside CadencR.
