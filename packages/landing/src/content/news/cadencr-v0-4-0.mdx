CadencR is local-first on purpose: your agents, terminals, worktrees, and project state stay on your machine. Version 0.4.0 adds **remote env** so another device can become a control surface for that same local workspace.

Pair a phone, tablet, or second computer by QR code or link, then keep a session moving from a browser: review a plan, approve work, send a follow-up prompt, steer model or permission settings, and use the terminal without moving the project to a hosted service.

## Local network or remote network

On the same Wi-Fi or LAN, remote env exposes HTTPS links for the detected local network addresses. Open one from another device, pair once, and the remote browser mirrors the host workspace.

Away from the local network, CadencR is designed around **Tailscale** rather than a public tunnel. The Remote Access dialog gives a `tailscale serve` command and accepts your `*.ts.net` hostname, then adds that hostname to the backend allowlist and points pairing links at it. The result is that your CadencR instance can be reachable anywhere you have an internet connection, but only from devices on your own tailnet.

## Built for companion devices

Remote env is not a separate workspace. The second device connects back to the host and mirrors live sessions, stream updates, terminal panes, LSP-backed editor access, and the current worktree context.

It also includes the mobile work needed to make that useful: responsive layouts, mobile drawers, safer viewport sizing, prompt and terminal fixes around on-screen keyboards, and a terminal key bar for `Ctrl`, `Esc`, `Tab`, and arrow keys.

## PWA and prevent sleep

The remote browser experience ships as an installable PWA with app icons, standalone display support, iOS viewport handling, and an update prompt so long-lived installed sessions can reload when the host serves a newer CadencR frontend.

There is also an opt-in **Prevent Mac sleep while hosting** toggle. When enabled on macOS, CadencR holds a sleep-prevention assertion only while remote access is on, so the host stays available for paired devices without changing power behavior silently.

## Also in v0.4.0

This release also adds Monokai and Monokai Light themes, a feature unarchive action, more predictable sidebar ordering, long-running custom actions without the old 300-second timeout, and a fix for terminal clear shortcuts.

For the full list, read the changelog in the [v0.4.0 GitHub release notes](https://github.com/merkr-software/CadencR/releases/tag/v0.4.0).
