Some releases are about one headline feature. **CadencR v0.10.0 is about making the whole app feel better every day.**

This release brings together dozens of quality-of-life improvements across conversations, Git workflows, agent controls, schedules, images, mobile sessions, and the sidebar. Individually, each change removes a small interruption. Together, they make CadencR faster to read, easier to trust, and more comfortable to keep open throughout a full coding session.

## Less hunting, less rebuilding context

CadencR now shows the ports opened by each conversation directly in the sidebar, so a preview server is easy to find. Reference another conversation with `@@` and you can reuse its live worktree before sending, instead of locating the branch and checkout by hand.

Prompt images also behave more like part of the conversation: unsent attachments survive conversation switches, screenshots render as images rather than encoded payloads, and the new viewer supports zoom, pan, copy, save, and keyboard navigation.

Git work received the same attention. Pushes now make Plain, Force with lease, and Force modes explicit, show the exact command, and can continue in the background with live output ready when you return. Stash diffs, untracked-file statistics, view controls, shortcuts, and small visual details are more accurate and predictable.

## Better visibility into recurring work

The new Usage Stats view records provider-native token totals by provider, model, and thinking effort, keeps the history when conversations are archived, and imports recent local provider history on first launch.

Schedules have grown from one-shot messages into recurring work. A schedule can run once, at an interval, or on a daily, weekly, or monthly cadence; post into an existing conversation or start a new one; and use the same references, commands, skills, models, modes, and profiles as the regular prompt composer.

Codex users can also enable Fast mode directly beside the model and thinking controls, with the choice persisted across the conversation lifecycle.

## A calmer app under load

Long streaming conversations now do less repeated Markdown and diff work, oversized tool payloads stay bounded without losing their structure, and Task or Agent sub-agent activity is presented as a cleaner, expandable timeline.

The release also fixes running mobile conversations that could surface repeated React errors, restores OpenCode Task sub-agent visibility, and smooths the visual boundary between the transcript and composer.
