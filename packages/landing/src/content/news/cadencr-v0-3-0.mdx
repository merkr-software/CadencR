CadencR started as an agent workspace, but an agent workspace still needs a good place to read and edit code. Version 0.3.0 is the release where the editor stops feeling like a side panel and starts becoming a real coding surface.

The headline is LSP support and the file tree rework around it. You can Cmd-click through code, see diagnostics in the editor, watch server status, and manage supported language servers from Settings. CadencR discovers installed servers when it can, downloads managed ones when needed, verifies those downloads before running them, and keeps their lifecycle tied to the workspace instead of leaving background processes around forever.

That matters because agent work is full of tiny human checks. An agent changes a symbol, you jump to its definition. It mentions a diagnostic, you inspect it in place. It opens a file you have never seen before, you search inside it, jump to a line, or make a quick manual edit without leaving the app.

The editor gained the workflows I missed most while using CadencR every day.

The biggest piece is language intelligence. CadencR now has an LSP host that connects CodeMirror to local language servers over WebSocket, with Cmd-click go-to-definition, symbol hover affordances, diagnostics, and a status indicator in the editor chrome. Settings now includes a language-server list, so you can see what CadencR found and what it can manage for you.

The language support is broader too. Rust Analyzer can be downloaded as a pinned managed binary, npm-backed servers can be installed automatically, and the catalog now covers everyday web files like TypeScript, JavaScript, JSON, YAML, HTML, CSS, Svelte, Vue, Astro, shell scripts, and Dockerfiles. Diagnostics show up with theme-correct tooltips, server messages are surfaced as toasts, and missing tools fail early with a readable error instead of a silent editor feature that simply does nothing.

Navigation and editing also got much closer to the workflows you expect from a code editor:

- in-buffer search and replace with `Cmd+F`
- go-to-line
- Markdown preview
- multi-cursor and multi-selection editing
- expanded syntax highlighting, including Astro
- editor-scoped shortcuts and a dedicated buffer keymap
- scratch buffers with `Cmd+N` and Save As
- clean-buffer sync when files change on disk
- safer dirty-state handling when reopening files
- better undo behavior immediately after opening a file
- active-line selection highlighting, active-tab polish, and a clearer status bar
- and many more

The goal is not to recreate every feature of a full IDE overnight. The goal is to make the common loop fast: inspect what the agent did, verify the relevant code, make a small correction, and get back to directing the work. Press `Cmd+?` any time to see the full keyboard shortcut list.

## Other improvements

The editor is the headline, but v0.3.0 also includes a reworked file tree, global theme drawer, One Dark and One Light themes, clearer agent verbosity modes, faster large-session opening, and a pile of stability fixes around drafts, diffs, archive confirmation, merge conflicts, and keyboard layouts.

For the full list, read the changelog in the [v0.3.0 GitHub release notes](https://github.com/merkr-software/CadencR/releases/tag/v0.3.0) once the release is live.

The agent is only half the product. The other half is the human feedback loop around it. Version 0.3.0 makes that loop tighter. You can let agents do more of the mechanical work, but you can also inspect, navigate, and correct their output without dropping back to another editor every thirty seconds.
